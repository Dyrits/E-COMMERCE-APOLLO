# E-COMMERCE-APOLLO

A GraphQL API for an e-commerce catalog (products, categories and reviews), built with Apollo Server.

## About The Project

A standalone Apollo Server 4 API serving products, categories and reviews from in-memory data, with queries and mutations defined in `schema/` and `resolvers/`.

### Built With

- Node.js
- Apollo Server 4
- GraphQL

## Getting Started

### Prerequisites

- Node.js

### Installation

```sh
npm install
node index.js    # serves the GraphQL endpoint (default: http://localhost:4000)
```
